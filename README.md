# Maharashtra-Climate-Impact-Intelligence-Power-BI-Analytics-Project
An interactive Power BI analytics project integrating Maharashtra’s weather, agriculture, and public health data from 2020–2025. The project explores climate patterns, crop production, agricultural performance, and disease trends through an interactive dashboard with dynamic filters, DAX measures, data modeling, and tooltip-based analysis.

# 📊 Project Overview
The **Maharashtra Climate Impact Intelligence Dashboard** is a Power BI analytics project that brings together climate, agriculture, and health-related data across Maharashtra for the period **2020–2025**.
The project explores patterns in rainfall, temperature, wind speed, crop production, agricultural seasons, and reported disease cases through interactive dashboards and detailed analysis pages.
The goal is to transform multiple datasets into a single analytical view that helps users explore how environmental, agricultural, and health indicators vary across years, regions, districts, and seasons.

# 📈 Key Insights
- The dashboard reports an average temperature of approximately **28.36** across the analyzed Maharashtra dataset.
- **Western Maharashtra** records the highest regional crop production at approximately **5.3M tonnes** in the displayed analysis.
- **Diarrhea** has the highest reported disease count in the displayed dataset, at approximately **118K cases**.
> These insights are based on the dataset and filters used in the dashboard and should not be interpreted as official statewide statistics.

The project focuses on **data modeling, exploratory analysis, visualization, and data storytelling** rather than presenting climate or health data as causal evidence.
